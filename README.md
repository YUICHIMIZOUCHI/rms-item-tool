# RMS商品一括編集ツール

楽天市場RMSの商品情報を一括ダウンロード・編集・反映するローカルWebアプリです。
無料の **RMS WEB API（Item API 2.0 / Inventory API 2.0）** だけで動作し、ブラウザ自動操作や有料サービスの契約は不要です。

編集はまずローカル（PC内のデータベース）に保存され、**［RMSに反映］を実行するまで楽天側は変更されません。**

## 主な機能

- **商品一覧ダウンロード** — 全商品をAPIで取得してローカルDBに保存
- **個別編集** — 商品名／キャッチコピー／商品説明文／販売価格／二重価格／販売期間／倉庫指定など（JSON直接編集で全項目対応）
- **一括編集** — 文字列置換、先頭・末尾への追加、価格一括変更（率・額・一律）、二重価格の設定/解除、倉庫入れ/出し、販売期間の設定/解除
- **Excel風の列フィルター** — 列見出しの▼から値のチェックリストで絞り込み。ページをまたぐ全選択にも対応
- **セール機能** — 対象商品に🏷フラグ → 値引き・二重価格・販売期間をワンクリック適用 → **終了日時に自動で元へ復元**。開始時点の値を履歴として2世代保存し、いつでも巻き戻し可能
- **復元予約** — 指定日時に価格・販売期間をスナップショットの値へ自動復元（実行時はRMSの最新データを取得して差分のみPATCH）
- **CSV取込／エクスポート** — 新規商品の一括登録（初期在庫設定つき）
- **商品複製**、**処理ログ**、**デモモード**（APIキーなしで全機能を試用可）

## 動作環境

- Windows 10/11 または macOS
- Python 3.8+
- 楽天市場出店契約と RMS WEB APIサービスの利用申請（無料）

## インストールと起動

### Windows（かんたん・EXE版）

[Releases](https://github.com/YUICHIMIZOUCHI/rms-item-tool/releases) から `rms-item-tool.exe` をダウンロードしてダブルクリックするだけ。Pythonのインストールは不要です。

※初回起動時に「WindowsによってPCが保護されました」と表示された場合は「詳細情報」→「実行」をクリックしてください（コード署名を行っていないための表示です）。
※設定・データはEXEと同じフォルダに保存されるため、書き込み可能なフォルダ（デスクトップ等）に置いてください。

### Python版（Windows / Mac）

```bash
git clone https://github.com/YUICHIMIZOUCHI/rms-item-tool.git
cd rms-item-tool
pip install -r requirements.txt
python app.py
```

またはフォルダを配置して `start.bat`（Windows）／ `start.command`（Mac）を実行。
ブラウザで http://localhost:8930 が開きます。

## RMS側の準備

1. RMSメインメニュー →［店舗様向け情報・サービス］→［WEB APIサービス］で利用申請（無料）
2. ［アプリ登録］で serviceSecret とライセンスキーを発行
3. ［利用機能編集］で以下を「利用中」にする
   - Item API 2.0：`items.search` / `items.get` / `items.upsert` / `items.patch`
   - Inventory API 2.0：`inventories.bulk.upsert`
4. 本ツールの［設定］タブにキーを貼り付け、デモモードを外して保存 → 接続テスト

※キーは `config.json` にローカル保存されます。**コミット・配布しないでください**（.gitignore済み）。

## 基本の流れ

```
商品一覧ダウンロード → 絞り込み・編集（ローカル保存） → RMSに反映 → ログ確認
```

詳細な操作方法は同梱の「取扱説明書」を参照してください。

## 注意事項

- 反映操作は取り消せません。必ず少数の商品でテストしてから本格運用してください。
- 自動復元（予約）はツール起動中のみ実行されます。停止中に時刻を過ぎた予約は「要確認」となり自動実行されません。
- RMSの仕様変更により動作しなくなる可能性があります。
- 本ツールの使用により生じたいかなる損害についても作者は責任を負いません（MITライセンス）。
